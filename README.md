# 同频 PULSE 健身伴侣 · Android 1.1.1

本轮为页面与交互改版，页面结构和修复详见 [UI-REDESIGN.md](UI-REDESIGN.md)。APK输出为 `dist/pulse-1.1.1.apk`，沿用1.1签名，可覆盖升级；没有自动更新GitHub Release。

Android 8.0+ 原生 Java 应用。暖白 / 深绿 / 浅荧光绿；三个场景动态插画。无账号、无 INTERNET 权限；报告仅在本机保存最近100份，可删除。清除数据/卸载会删除报告，系统备份已关闭。

## 使用

选择单车、跑步机或器械，设置目标、警示参考值、30–600秒休息及中文语音风格；开始后扫描并选择标准BLE设备。Android 8–11需定位权限及系统定位，Android12+需附近设备权限。模拟模式必须开始前明确开启，数据与报告标有模拟；断连绝不转为模拟。设备必须开放标准BLE服务。华为、小米仅为适配目标，没有全型号兼容承诺。

- BLE HR 180D/2A37支持8/16位；可选 RSC 1814/2A53速度/步频、CSC 1816/2A5B曲柄踏频。CSC不推算距离。心率超过10秒、速度/步频/踏频超过5秒即缺失，不再累计过期值。
- 跑步机优先对新鲜设备速度积分；无有效设备速度时可用手动km/h估算。报告标为设备积分、估算或混合。无速度不积累，暂停冻结；不从心率推算速度或距离。
- 单车8秒稳定变化、20秒切换间隔，180秒可鼓励；跑步机12秒/30秒/300秒；默认恢复分别60、120秒。器械默认90秒组间休息。到时只提醒，不启动下一组或控制设备。
- 器械自动辅助判组是**未经实机验证的启发式推测**：心率EMA当前权重0.25，20个有效秒基线；高于基线12BPM持续8秒推测开始；至少20秒且较观察峰值下降10BPM持续10秒推测结束。缺失、暂停、警示、休息时不推测。自动组暂存，确认才计入目标，可删除；可手动起止和丢弃当前组。未完成组结束训练时排除。不推算次数、负重、力竭或动作质量。
- 原创程序合成88/116/136BPM四小节循环，约1秒交叉渐变；不含外部音乐采样。三种措辞/语速使用**系统离线中文TTS音色**，必须安装系统离线中文语音包；缺失时界面明确显示，不能保证所有ROM预装中文。语音压低音乐；失去音频焦点和耳机断开暂停，需手动继续。来电通过系统音频焦点处理中断，厂商行为需真机验证。
- 默认心率170仅为用户可调警示参考值，并非通用安全阈值；优先舒缓及提示降低强度，覆盖普通鼓励。
- 前台服务、常驻通知和partial wake lock承载锁屏采集、计时及播放。系统强杀/省电限制仍可终止，不会自动恢复旧训练。计时采用单调时钟，暂停排除；速度积分每个实际调度的活动秒一次，非医学测量。
- 结束需确认，保存后呈现并语音总结时长、平均/最高心率、有效覆盖、步频/踏频、场景里程/组记录；曲线以活动训练时间为横轴，缺失断开。未配备相应数据的字段显示缺失。

未实现：个人曲库、云端大模型鼓励、真人音色、厂商私有SDK。未授权的公众人物音色不在应用中。

## 构建、算法测试及签名

依赖JDK21、Android SDK platform35、build-tools35.0.0、Python3、zip。使用官方SDK与JDK。没有Gradle/网络运行时依赖。

```sh
python3 scripts/music.py
export JAVA_HOME=/path/to/jdk21
export ANDROID_JAR=/path/to/sdk/platforms/android-35/android.jar
export BUILD_TOOLS=/path/to/sdk/build-tools/35.0.0
# 可选：SIGNING_KEYSTORE、SIGNING_PASSWORD，通过私密环境变量提供；alias为pulse
bash scripts/build.sh
```

脚本先运行纯Java算法/会话流程断言，再编译、dex、打包、对齐、可选签名和验证。源代码、音乐合成器与测试全包含在源码归档。音乐WAV也随源归档保存。APK min26、target32，支持直接侧载；并非Play商店合规发布。此重建使用新签名，旧签名丢失时不能保证覆盖安装旧APK。

发布采用独立应用源码分支和独立Release，不修改官网文件、不向main推送应用代码。签名私钥不在公共源码或Release中；维护后续覆盖更新必须保管当前私钥。

## 模拟器内界面回归

安装新版APK后设置与构建相同的环境变量以及 `ADB`，运行 `TEST_RUNNER=UiRunner bash scripts/device-test.sh`。测试通过Android UiAutomation注入触摸事件，检查真实页面跳转、表单、三场景训练、休息、组确认和报告删除，并将截图写入设备应用的外部文件目录 `ui-validation/`。这只验证模拟器交互，不替代实体设备测试。运行 `TEST_RUNNER=FlowRunner bash scripts/device-test.sh` 复核服务与报告流程。脚本会把失败或没有通过结果的测试作为失败退出。
